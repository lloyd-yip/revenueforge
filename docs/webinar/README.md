## The three traps

**1. The skeleton is not the script.** `webinar-script.md` is titled "Master Skeleton" and holds
beat-level notes. If you need the words Lloyd actually says, they are in the sections draft — and
only for the back half. **The front half has never been written as prose.**

**2. Sections 5–6 were never merged back.** The skeleton's sections 5 and 6 are superseded by the
sections draft and were not updated. Two sources of truth for the same sections, and the older one
looks authoritative because it lives in the file called "script".

**3. The sections draft supersedes itself internally.** It contains multiple versions of 6.2 in
sequence. The current one is marked **"6.2 — FINAL ASSEMBLY (supersedes all versions above)"**.
Earlier 6.2 blocks in the same file are dead. Read to the bottom before using anything.

# RevenueForge

**Planning-stage business. No product built yet. This repo is the planning home — every
RevenueForge document lives here or is indexed here.**

RevenueForge sells revenue-engine automation to $5–15m knowledge businesses: a prescribed stack
of AI systems, implemented and then operated on our infrastructure for a recurring fee.

Status: **planning**. No app, no Railway, no Supabase. Infra comes only when a build actually needs it.
